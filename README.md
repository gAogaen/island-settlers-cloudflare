# 島の開拓者 — Cloudflare版

CATANを参考にした、3〜6人用のブラウザ対戦ゲームです。地形イラストには公式ルールブックに掲載された紙版の画像を使用しています。出典はASSETS.mdに記載しています。CATANやBoard Game Arenaの公式サービスではありません。Cloudflare WorkersがAPIと静的ファイルを配信し、Durable Objectsがルームごとの対戦状態を保持します。

## 対応している遊び方

- 3〜6人の部屋作成・コード参加
- 3〜4人用19タイル、5〜6人用30タイルの盤面
- 初期配置の蛇行順、初期開拓地と道、2軒目の隣接資源
- サイコロ、資源生産、銀行の4:1交換、港の3:1・2:1交換
- プレイヤー同士の資源交換提示と承認
- 道・開拓地・都市、発展カード、盗賊、7の出目での手札調整
- 騎士、豊作、独占、街道建設、勝利点カード
- 最長交易路、最大騎士力、10点勝利
- 5〜6人戦の特別建設フェーズ
- スマートフォンとPC向けの盤面表示

## Cloudflareへ配置

1. Node.jsを用意し、このフォルダで `npm install` を実行します。
2. `npx wrangler login` でCloudflareへログインします。
3. `npx wrangler dev` でローカル起動します。
4. `npx wrangler deploy` でWorkersへ配置します。

Durable ObjectはSQLiteストレージで作成する設定です。初回デプロイ時にCloudflare側で確認が表示された場合は、その案内に従ってください。公開URLを友達へ共有すれば、同じURLから部屋へ参加できます。

## 現在の実装範囲

アカウント登録なしで遊べる試作版です。ルームへの再接続には同じブラウザのローカル保存情報を使います。対戦中の状態はDurable Objectsへ保存されます。通信は短い間隔で状態を取得する方式です。

実装はCATANの基本ルールに沿っていますが、公式アプリや物理版の全シナリオ・全例外処理を網羅したものではありません。5〜6人用の特別建設では、順番のプレイヤーが建設または発展カード購入を行えます。対戦ログや部屋の整理、切断者の離席処理などは簡易仕様です。

## ファイル構成

- `src/worker.mjs` — API、ゲームルール、Durable Object
- `public/index.html` — 画面構造
- `public/style.css` — レスポンシブUI
- `public/app.js` — 盤面描画とブラウザ操作
- `wrangler.jsonc` — Workers、静的アセット、Durable Object設定


## 操作と対戦の継続

- 建設モードを選ぶと、置ける交差点・辺のみ緑色で表示します。
- 街道建設は道を1〜2本選んでから「確定」します。選択途中ならキャンセルしても資源やカードは消費しません。確定済みの操作を戻す機能ではありません。
- サイコロの結果と同時に、参加者それぞれの獲得資源と銀行不足を表示します。今回の生産タイルを盤面上でも強調します。
- 「ホームへ」で戻っても対戦の参加情報は保持します。ホームの「対戦に戻る」から、同じブラウザで復帰できます。ブラウザの保存データを削除した場合や別の端末での復帰は対象外です。
- 交渉では各資源の「渡す」「受け取る」枚数を指定し、複数種類をまとめて交換できます。承諾時にも双方の手札を確認します。
- ゲーム終了後は「同じメンバーで再戦する」を押して準備します。全員が準備完了すると同じ部屋・同じ参加者で新しい盤面が生成されます。再戦も別の対戦として戦績に記録します。

## 自動確認

`npm test` で、3〜6人の初期配置、建設可能場所、資源配布、複数資源交換、復帰、再戦、画面表示のテストを実行できます。UIのテストはDOMを模した環境で行い、実ブラウザでの画面操作テストを置き換えるものではありません。

### 観戦

ホームの「部屋に参加」で部屋コードを入力し、「この部屋を観戦する」を押すと、プレイヤー枠を使わずに観戦できます。開始前・対戦中・終了後の部屋に入れ、盤面、ログ、サイコロ、資源獲得を見られます。観戦者は操作や再戦の準備ができず、手札や発展カードの内容は表示されません。観戦画面のURLは観戦用として共有できます。部屋コードを知っている人は観戦可能です。

### 操作待ちの通知

自分のターン、初期配置、特別建設、盗賊移動、7による手札調整で、ブラウザ上の操作が60秒間ない場合に、操作を妨げない通知、タブ名、通知音でお知らせします。操作がない間、表示を続けて60秒ごとに経過時間を更新し、通知音を鳴らします。通知音は音のオン・オフ設定に連動します。クリックやキー入力などで通知は消え、その後も操作待ちが続けば再度表示されます。ページを開いていない間のプッシュ通知ではありません。

### 発展カードの使い方

使用ボタンを押すと効果と操作手順を表示します。豊作は銀行の残数を見ながら資源を2枚選び、独占は資源を1種類選んで確定します。騎士は確認後に盗賊を移動します。街道建設は盤面で道を1〜2本選んで確定し、確定前に取り消せます。失敗した操作はカードや盤面に反映されません。

### 操作のお知らせ

他のプレイヤーの操作は画面上に約4秒間表示されます。観戦中も表示され、盤面の操作を妨げません。更新間隔は通常約2.2秒です。入室前の過去の操作は表示せず、ゲームログで確認できます。

バースト対象者には捨てる枚数を演出で表示します。別のプレイヤーが自分の開拓地・都市に隣接する土地へ盗賊を置いたときは、通知と盤面の点滅でお知らせします。どちらも短時間で消え、操作を遮りません。

盗賊は案内画面から盤面で移動先を選び、資源を奪える相手が複数いれば1人選んで確定します。銀行・港との交換とプレイヤー間の交渉は、手札欄のボタンから専用画面で行います。交換提案を受けた側は従来の確認画面から受諾・拒否できます。

バーストで手札を捨てる場合、出目の画面を閉じた後に選択画面が開きます。各資源の＋・−で必要枚数を選んで確定します。画面を閉じた場合も「捨てる資源を選ぶ」から再表示できます。

## タイムボム

ゲーム一覧からタイムボムを選べます。3〜8人の基本ルール（スパイ・2人用NPCなし）です。ユーザー提供の旧Google Apps版README、script.html、Code.gsに記載された人数別構成、4ラウンド、人数分の公開、ニッパーの受け渡し、未公開カードの再配布、3種類の勝利条件を参考に実装しました。

- 自分の席が手前に固定され、伏せカードをテーブルに並べます。本人もカード位置を知ることはできません。自分の陣営と残っているカードの種類別枚数だけが分かります。
- 全員が手札を確認してから進行します。ニッパー係が相手を指名し、カードを選んで確認後に公開します。自分のカードは切れません。
- 人数分の公開でラウンド終了。ニッパー係のボタンで未公開カードのみを回収・シャッフル・再配布します。
- 爆発／解除／時間切れの判定、陣営公開、ホストによる再戦、相談チャット、観戦、招待リンク、同じブラウザでの復帰に対応しています。
- 部屋コードと同じ名前を入力すると、元のプレイヤーとして復帰できます。ブラウザに保存した参加情報からの復帰も引き続き使えます。名前だけで復帰できるため、同じ部屋では各自異なる名前を使用してください。
- 既存のROOMS Durable Objectを使い、カタンと別の部屋名前空間・保存キーで管理します。Cloudflareのバインド追加は不要です。
- 本人の内訳を含め、伏せカードの種類の配列順を外部へ返しません。観戦者には非公開情報や参加トークンを返しません。

`npm install` 後の `npm test` には、タイムボムのエンジン/APIテストとlinkedomによる複数クライアントのDOM結合テストも含まれます。実ブラウザの表示・音声確認を代替するものではありません。

## boardgame.un0wn.workers.dev の入口

`npm run deploy:boardgame` で、既存の `island-settlers-online` Workerに接続する `boardgame` Workerを作成します。Cloudflareアカウントのworkers.devサブドメインが `un0wn` の場合、URLは `https://boardgame.un0wn.workers.dev` になります。ゲーム本体を更新するGitHub連携は引き続き元のWorkerに接続します。入口は本体の最新版へリクエストを転送するため、通常のゲーム更新時には入口の再デプロイは不要です。元のWorkerは削除しないでください。

URL変更でブラウザ内の保存領域は別になります。旧URLで保存された参加情報・戦績は新URLへ自動移行されません。新URLで新しく部屋を作って遊ぶ運用を推奨します。

カタンも部屋コードと同じ名前で復帰できます。開始済み・満員・終了済みの部屋でも元のプレイヤーを引き継ぎ、新しい席は追加しません。旧データに同名の参加者が複数ある場合は、取り違え防止のため保存済み参加情報から復帰してください。

## ペンギンパーティ

`/penguin.html` から2〜6人で遊べます。専用の氷上ピラミッド画面、5色のオリジナルSVG、固定手札、配置可能位置のハイライト、配置確認、効果音、ラウンド結果、同点を含む最終順位、相談チャット、観戦、同名復帰、再戦に対応します。

基本ルール：36枚（緑8枚・ほか各7枚）、底辺8枚、上段は直下2枚のいずれかと同色。置けない人は残り手札枚数ぶん失点、手札を出し切ると失点を最大2点返却（下限0）。人数ぶんのラウンドを行い開始プレイヤーを1人ずつ交代します。2人用は14枚ずつ・底辺7枚、5人用は余り1枚を底辺に配置します。最初の開始プレイヤーはオンライン用にランダムに決定します。置けなくなったときの失点・ラウンド離脱はサーバーが自動処理します。次ラウンドはホストが結果画面のボタンで開始します。

ルール照合に使った資料：
- 発売元 https://www.newgamesorder.jp/games/penguinparty
- AMIGO説明書（著作表示を含むPDF） https://www.brettspiele-report.de/wp-content/plugins/download-monitor/download.php?id=135
- 日本語紹介 https://www.mobius-games.co.jp/Amigo/Ping-Party.html

同じROOMSバインドの別名前空間 `penguin:` と保存キー `penguin` で動きます。Cloudflareの追加設定は不要です。`npm test` は2〜6人の全ラウンド、配置条件、失点、公開情報、API復帰とDOM結合テストを含みます。実ブラウザの視覚・音声検証は未実施です。
