# 赤い扉：追加カード実装（2026-11-02）

ユーザー提供のカード写真3枚（上級01B〜23B、PR-01B）を根拠として実装。初期設定は基本16枚のまま。作成・開始前にカードを個別選択できる。

既存3種類（FBI手帳、脱出口の影、道化の灯）を更新し、新規21種類を追加。公式の難易度40段階プリセットは、構成表が提供されていないため含めない。

## 重要な処理

- 数字の入れ墨：全員が秘密に1〜5を確定してから公開。合計7以外は最大値の全員が死亡。既に死亡している人も写真の「全員」に従い数字選択に参加する。
- カードキー：2枚を選び、選択した順で通常のカード効果を処理。再配置が発生しても次のカードの同一性を維持する。所持者が死亡すると連続探索を中止。
- 軍人のナイフ：元の手番の人が扉を選んでから、代わりに処理する人を選択。終了後は元の人の次へ。
- 神経ガス：所持者の手番開始時に90度。4回で死亡。防弾チョッキ不可、ガスマスク有効。
- レントゲン写真：場に戻さず所持者の前に残す。所持者死亡中のみ必要な鍵が1本減る。復活で元に戻る。
- 絶叫の罠：所持者の手番開始時に180度。2回転時に表向きの手がかり0枚なら死亡、2枚以上なら除外、1枚なら何も起こらず残る。
- 教団の魔導書：全員の罠・催眠ガスを怪物襲撃に変更。殺人鬼でも伏せて回避できない。カードに防弾チョッキ除外の指定がないため通常の死亡防御処理を適用する。
- 守りの鍵：銀の鍵として計数。採用時に銀の鍵1枚と差し替え。死亡時に本人へ使用確認。使用すると死亡とその際の持ち物の回収を回避する。
- 仮面の囁き：取りついた扉を再配置から除外。位置固定を画面に表示。
- 沈黙の毒蜘蛛：ゲーム内チャットをサーバーで拒否。外部の音声通話は制御できないため説明を表示。
- 反魂の香：使わず伏せる／使って除外する選択。使用時は全員の鍵だけを場に戻して再配置し、死亡者1人を復活。
- 復活カード採用時は、死亡後に復活する人が伏せ情報を知るのを防ぐため、死亡者の神視点を無効化。基本セットだけの神視点は従来どおり。
- FBI手帳は選んだカード解決後に実際に場から除外（以前の実装で再配置に紛れ戻る不具合を修正）。
