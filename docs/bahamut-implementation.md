# はらぺこバハムート

既存6ゲームを保持して7番目に追加。公開先 `/bahamut.html`、API `/api/bahamut`、Durable Object名と保存キーは `bahamut` で他ゲームから分離。既存のROOMSバインディングを再利用し、移行は不要。

全16枚、先手初回の制限、任意のまもの攻撃順、打ち消し／打ち消し返し、追加プレイ回数、ドロー中の山札再構築、手札整理、ライフと勝敗、再戦、トークン復帰、招待URL、観戦に対応。プレイしたカードは効果が終わるまで山札の再構築に入れない。対象選択は打ち消し判断の後で行う。山札・相手手札の選択肢は効果使用者にだけ送る。リビジョンとmatchIdで古い操作を拒否し、失敗時は状態を保存しない。

カードはオリジナル画像を複製せず、名前・効果の要約と記号による表示。公式の説明書と全16カード画像、Q&Aを照合した。参照：https://jelly2games.com/harapeko

検証：全カードの処理、打ち消し段階、コスト、攻撃順、観戦非公開、40試合の終了までのシミュレーションでカード16枚／打ち消し6個の保存を確認。DOM/API結合で部屋・参加・開始・プレイ確認・両打ち消しモーダル・観戦・不正操作の拒否を確認。実ブラウザの視覚確認は未実施。
