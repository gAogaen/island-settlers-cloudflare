# ロケット団 進化カード画像監査

対象は main の d9521eb06980e8d4cc993c91cea513e2410e6d60 にある WebP 74枚。ローカルと GitHub Actions の JSON はバイト単位で一致した。74枚すべてデコード成功。寸法は 600×840 が30枚、630×880 が7枚、745×1040 が37枚。再補正後も同じ枚数と寸法。

## 測定方法

Lv.3 の card_001〜card_030 を進化系統ごとに参照し、ミニリュウ系統にはカイリューを使用。測定時は300×420へ統一。白地は下部の6行帯から低彩度・高輝度の画素を抽出。名前帯は位置を探索し、暗色画素の中央値を測定。左右の外枠は下半分で黒線の内側へ明度が立ち上がる位置を追跡し、外側の色と境界の明度を比較した。

黒線を追跡できたのは左67枚、右55枚。傾きと直線からの残差は部分測定値。四辺・角を含む歪みの合否や境界影の全数判定は保留した。黒線のすぐ外側の中央値には、Lv.3より大きい明度低下が見られた。黒線のアンチエイリアスや印刷の濃淡も含むため、この値だけで影とは判定していない。フシギソウとフシギバナの名前帯はそれぞれ (84,78,72) と (93,83,77)、左外枠は (89,144,66) と (87,156,61)。この補正では名前帯と外枠の色を変更していない。
