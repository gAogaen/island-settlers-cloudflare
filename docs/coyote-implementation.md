# コヨーテ（8番目のゲーム）

既存7ゲームを保持して `/coyote.html` を追加。`/api/coyote`、Durable Object名 `coyote:CODE`、保存キー `coyote` で他ゲームから分離。既存のROOMSバインディングを使用し、移行不要。

## ルールと非公開情報

ニューゲームズオーダーの現行説明書（公式ページの「コヨーテ ルール.pdf」）とFAQを照合。36枚、2〜10人、開始ライフ3（開始前に4も選択可）、1以上の整数を時計回りに宣言、コヨーテによる判定、脱落、最後の1人の勝利と再戦を実装。仮面カードを使う追加ルールは対象外で、その旨を画面にも明記。

「？」の追加カード、最大の正の数字1枚だけを0にする効果、最後の2倍計算、夜カードでの全36枚の再シャッフル、山札不足時の捨て札再利用に対応。負けた人が次ラウンドを開始し、脱落した場合はその勝負の勝者から開始。

本人の現在のカードと山札順・合計値はAPIから除外。観戦者も答え合わせまで全カードを非公開にして、観戦タブで自分のカードが見えることを防ぐ。脱落後は対戦を観戦可能。トークン復帰・手番権限・リビジョンとroundId/matchIdの検証・失敗時の非保存を実装。次ラウンドの確認だけは同一ラウンド内の古いリビジョンを許容し、同時確認の競合を避ける。

## 卓と操作

開始後も席番号と位置を保持。各参加者の席を手前に回転して表示し、時計回りの順番を維持。現在の手番・次の席・進行矢印・前後の参加者・席順一覧を併記し、脱落した席は残して飛ばす。狭い画面は縦長の卓にして人数に応じて席間隔を増やす。

手番の操作は卓の上部に配置し、スマホでは画面下部にも固定表示。数字入力・コヨーテ確認・答え合わせ・ルール・カード構成・強制進行・再戦にモーダルを使用。結果は生存者全員が確認すると次へ進む。切断時などはホストの確認付きで先へ進める。招待URL、再接続表示、任意の手番通知音、共通テーマ切替に対応。カードの絵柄は複製せず、数値と記号で表示。

## 検証

- 全特殊効果、同値判定、脱落時の開始者、固定席・脱落飛ばし、同時確認、カード再構築を検証。
- 2〜10人で72試合を最後までシミュレーション。各操作後に36枚の保存を確認。再戦で全員が復帰。
- DOM/API結合で10人の作成・参加・開始、宣言・コヨーテ・結果モーダル、非公開情報、次ラウンドへの確認を検証。
- 320/390/760/1000/1280px相当、2〜10席の配置で座席同士の間隔を検証。実端末での見え方は別途確認が必要。
- 既存7ゲームを含む全テストとWrangler dry-runを実行。
