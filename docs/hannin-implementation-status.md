# 犯人は踊る — 実装状況

作業ブランチ: `feature/hannin-wa-odoru`

## 実装

- 3〜8人の部屋作成・参加・再接続・招待・観戦・再戦
- 手札をサーバーで保持し、本人以外と観戦者には非公開
- 第三版の32枚と人数別のカード選定、第一発見者からの時計回り進行
- 全カード効果、犯人・探偵・いぬの勝利、たくらみの共犯処理
- 手札移動・公開・非公開選択、古い操作と手番外操作の拒否
- ロビーの待機人数、効果処理中の選択者、手札ごとの効果説明を表示
- 初回の遊び方説明、任意の再表示、ゲーム一覧への掲載

## ルール照合

第三版の人数、32枚構成、第一発見者から始める進行、手札を使う流れ、探偵・犯人の勝利条件を、すごろくやの製品案内と照合しました。第三版で少年が追加され、いぬの効果が変更された点も確認しています。オンラインでは少年の効果を「プレイヤー本人だけに犯人名を表示」として実装しています。
